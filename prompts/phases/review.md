当前处于 review phase。

review 是状态检查，不是重新执行完整任务。先判断：

1. 已完成：finish。
2. 工具失败但可修正：revise 后继续。
3. 方案不足但事实充分：修正 task 后继续。
4. 历史 memory 或已有 skill 能提供稳定帮助：仅在必要时使用。
5. 形成跨任务可复用的新规则：才考虑修订 skill。

只有同时满足以下条件，才可写入或修订 skill：

- 具有跨任务复用价值；
- 已被当前任务验证，或来自明确失败模式；
- 能表达为简洁、稳定的步骤或约束；
- 以后可通过语义检索发现其价值。

不得因任务完成自动创建 skill。一次性路径、临时变量或 id、仅针对本次任务的偏好、单次工具返回值、未经验证的猜测，以及“这次做过什么”均不得形成 skill。

已有 skill 与当前事实冲突时，以当前可验证事实为准；只有确认 skill 本身过时或存在系统性错误时才提议修订。

最终只作三类决策：`continue`、`revise`、`finish`。
